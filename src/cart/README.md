# src/cart/

**장바구니 상태 관리**

여행자가 고른 메뉴와 수량을 담아두고 원화 총계를 계산합니다. Spec은 `docs/specs/cart.md`.

## 파일

| 파일 | 역할 |
|---|---|
| `store.py` | 카트 담기/빼기, 같은 음식 합치기, 0이면 삭제, 총계 계산 |

## 규칙

- 같은 **메뉴판 줄**은 한 줄로 합칩니다 (`food_id` + `menu_text` 기준, `store.py`의 `_line_key()`).
  `food_id`만으로 묶으면 메뉴판에 따로 인쇄된 "물만두 5,000"과 "군만두 6,000"이 한 줄이 돼
  총계까지 틀립니다. `menu_text`가 없으면(좌표 없이 매칭된 옛 경로) `food_id`만으로 묶습니다
- 수량은 음수가 될 수 없고, 0이 되면 그 줄을 지웁니다
- 모든 함수는 카트 **전체** 상태를 돌려줍니다 — 프론트가 부분 갱신을 조합할 필요가 없게

## 저장 위치

서버 프로세스 메모리(`dict`)에만 둡니다. 재시작하면 비워지고, 워커를 여러 개로 띄우면
공유되지 않습니다. 영속 저장은 Spec의 Out of Scope입니다.

로그인이 없는 서비스라 계정·세션 대신 브라우저가 만든 카트 ID(UUID)로 구분하며,
`X-Cart-Id` 헤더로 받습니다.

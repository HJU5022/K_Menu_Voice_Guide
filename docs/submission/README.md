## 이 폴더를 만든 원칙

1. 저장소에 없는 것을 있다고 쓰지 않는다 — 특히 STT.
2. 측정 조건이 현재 배포본과 다른 수치는 그 사실을 함께 적는다.
3. 파인튜닝이 **진 항목**(가격 숫자 인식)을 숨기지 않는다. 대응까지 함께 보이는 것이 오히려 근거가 된다.
4. 캡처는 실제로 앱을 돌려서 찍는다. 못 찍은 화면은 "미확보"로 남긴다.

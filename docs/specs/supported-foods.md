# Spec — 지원 음식 목록 (Supported dishes)

## Why

- **페르소나**: 한국어를 못 읽는 여행자. 식당 앞에서 이 앱을 처음 켰다.
- **상황**: 메뉴판을 찍기 전에 "이 앱이 내 앞의 메뉴를 알아볼 수 있는지" 확인하고 싶다.
- **문제**:
  1. 사진을 찍어 분석이 끝나야만 지원 여부를 알 수 있다 — 실패하면 그때까지의 대기가 헛수고다.
  2. "Unsupported dish" 안내를 받아도 *무엇이* 지원되는지 알 수 없어, 다시 시도할지 판단할 근거가 없다.
  3. 지원 범위가 어디까지인지 설명하는 화면이 앱 어디에도 없다.
- **측정 지표**: `unsupported_food` 응답 뒤 재촬영 시도 비율, 설정 화면 진입 후 이탈률.

## Goal

- **해결 목표**: 카메라 화면의 톱니바퀴 → 설정 화면에서, 이 서비스가 안내할 수 있는 음식 전체를 이름으로 확인할 수 있다.
- **성공 기준**
  - 목록은 DB에 등록된 음식 **전부**를 보여준다(현재 50개). 일부만 추려서 실제보다 좁거나 넓게 보이지 않는다.
  - 영문명 + 한글명을 함께 보여준다 — 여행자는 영문으로 찾고, 메뉴판에서는 한글로 대조한다.
  - 목록을 못 불러와도 설정 화면의 나머지 기능은 그대로 쓸 수 있다.
- **Out of Scope**: 검색·필터, 사진 썸네일, 맵기·가격 표시, 카테고리 분류, 페이지네이션, 목록에서 상세 화면으로 이동.

## What

**Happy Path**
1. 카메라 화면에서 톱니바퀴를 누른다 → 설정 화면이 열린다.
2. 설정 화면이 열릴 때 `GET /api/foods`를 호출한다.
3. "Supported dishes" 섹션에 총 개수와 함께 음식 목록이 뜬다.
4. 목록이 길므로 섹션 안에서 스크롤한다 — 설정 화면의 다른 항목이 밀려나지 않는다.

**Edge Cases**

| # | 상황 | 처리 방식 |
|---|---|---|
| EC-01 | 목록 요청 실패(서버 꺼짐·네트워크) | 섹션에 짧은 오류 문구만. 설정 화면의 다른 항목은 정상 동작 |
| EC-02 | 응답을 기다리는 중 | "Loading…" 표시. 빈 목록을 "지원 음식 없음"처럼 보여주지 않는다 |
| EC-03 | DB에 음식이 하나도 없음 | 빈 목록임을 그대로 알린다(오류 아님) |
| EC-04 | 설정 화면을 닫았다 다시 연다 | 다시 불러온다 — 담당자가 DB에 음식을 추가했을 수 있다 |

## How

```
GET /api/foods
인증: 없음

응답 200:
[
  { "food_id": int, "name_kr": string, "name_en": string }
]
```

- 정렬: 영문명 오름차순. 여행자가 영문으로 훑기 때문이다.
- 데이터 출처: `src/db/cache.py`의 `get_foods()` — 서버 시작 시 올려둔 메모리 캐시라 요청마다 DB를 치지 않는다.
- 목록에 사진·맵기·가격을 싣지 않는다. 이 화면의 질문은 "무엇을 지원하나"이지 "무엇을 먹을까"가 아니다.

## AC (Given-When-Then)

**AC-01 · 등록된 음식을 전부 돌려준다**
- GIVEN: foods 테이블에 음식 N개
- WHEN: `GET /api/foods`
- THEN: 길이 N인 배열. 각 항목에 `food_id`·`name_kr`·`name_en`이 있다

**AC-02 · 영문명 순으로 정렬한다**
- GIVEN: 입력 순서가 뒤섞인 foods 데이터
- WHEN: `GET /api/foods`
- THEN: `name_en` 오름차순으로 정렬되어 나온다

**AC-03 · 음식이 없어도 200이다**
- GIVEN: foods 테이블이 비어 있다
- WHEN: `GET /api/foods`
- THEN: 200과 빈 배열 (404 아님)

**AC-04 · 목록 실패가 설정 화면을 막지 않는다 (프론트)**
- GIVEN: 서버가 목록 요청에 실패한다
- WHEN: 톱니바퀴로 설정 화면을 연다
- THEN: 지원 음식 섹션에만 오류 문구가 뜨고, 언어·동의 토글과 앱 정보는 정상 동작한다

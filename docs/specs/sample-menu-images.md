# Spec — 샘플 메뉴판 이미지와 체험 버튼 (아직 착수 안 함)

> **상태: 착수 전.** 2026-08-23 브레인스토밍에서 확정됐으나 분량이 커서 뒤로 미뤘다
> (2026-08-24). 이 문서는 그때 정한 요구사항을 잃지 않으려고 남긴다.
> 웹 화면 본체는 `frontend/docs/web-app.md`가 다룬다.

## Why

- **페르소나**: 포트폴리오 링크만 받아 혼자 들어온 면접관. 옆에서 설명해줄 사람이 없고,
  **한국어 메뉴판 사진도 없다.**
- **상황**: 지금 첫 화면은 카메라 입력과 파일 업로더뿐이다. 올릴 사진이 없으면 화면을
  넘길 방법이 아예 없어서, 서비스가 무엇을 하는지 확인조차 못 하고 나간다.
- **문제**: 시연 자리(조원이 옆에서 설명)에서는 문제가 없지만, 링크만 공유되는 자리에서는
  **아무것도 못 하는 화면**이 된다. 우리 결과물을 볼 사람 대부분이 후자다.
- **측정 지표**: 사진 없이 들어온 방문자가 버튼 하나로 첫 화면 → 후보 → 상세까지 완주한다.

## Goal

- **해결 목표**: 직접 만든 샘플 메뉴판 이미지를 첫 화면에 놓고, 누르면 업로드한 것과
  똑같이 분석되게 한다.
- **성공 기준**:
  1. 샘플 이미지 **3장**이 저장소에 있고, 각각 `POST /api/analyze`에서 후보가 여러 개 나온다.
  2. 첫 화면에서 샘플 버튼만으로 상세 화면까지 갈 수 있다(파일 선택 없이).
  3. 기존 카메라·업로드 기능이 그대로 동작한다.
- **Out of Scope**: 실제 식당 메뉴판 사진 사용, 다국어 메뉴판, 샘플 자동 생성 도구.

## What

**Happy Path**

1. 첫 화면에 샘플 메뉴판 3장이 썸네일/버튼으로 보인다.
2. 하나를 누르면 그 이미지 바이트를 그대로 `POST /api/analyze`에 보낸다.
3. 이후 흐름은 업로드했을 때와 완전히 같다(`session_state["image"]`에도 같은 바이트를 담는다).

**Edge Cases**

| # | 상황 | 처리 방식 |
|---|---|---|
| EC-01 | 샘플 파일이 없거나 읽히지 않음 | 그 버튼만 감추고 나머지 화면은 정상으로 그린다 |
| EC-02 | 샘플 분석 중 서버 연결 실패 | 업로드와 같은 EC-07 화면(연결 실패 안내)으로 간다 |

## How

**만들 이미지 3장**

1. **1단 세로형** — 한 열로 메뉴가 나열된 형태
2. **2단형** — 좌우 두 칸. **이걸 제대로 읽는 것이 이 서비스의 강점**이라 반드시 포함한다
3. **3단형 또는 카테고리 구분이 있는 복잡한 형태**

**요구사항**

- 메뉴 이름은 **아래 지원 50개 안에서만** 고른다. 밖의 이름을 쓰면 후보가 안 나와서
  체험이 실패한다. 각 장에 8~20개.
- 가격 표기를 섞는다: `₩12,000`, `12,000원`, `12,000`, `小 31,000 / 大 38,000`
- 일부에는 수식어를 붙인다: 마늘보쌈, 매운갈비찜, 해물파전
- 가게 이름·카테고리 헤더·구분선을 넣어 실제 메뉴판처럼 만든다
- **한글 폰트를 반드시 포함해서 렌더링한다** — 기본 폰트로 그리면 한글이 네모(□)로 나와
  OCR이 아무것도 못 읽는다
- 저장 위치: `static/samples/`. 파일당 500KB 이하
- **저작권**: 실제 식당 메뉴판을 베끼지 않는다. 가상의 가게 이름으로 직접 만든다

## AC

**AC-01 · 샘플이 실제로 후보를 만든다**
- GIVEN: 만든 샘플 3장이 있다.
- WHEN: 각각을 `POST /api/analyze`에 보낸다.
- THEN: 세 장 모두 `status`가 `candidates_found`이고 후보가 여러 개 나온다. (후보 수를 기록한다)

**AC-02 · 사진 없이도 완주한다**
- GIVEN: 방문자가 아무 파일도 올리지 않았다.
- WHEN: 첫 화면에서 샘플 버튼 하나를 누른다.
- THEN: 후보 선택 화면을 거쳐 상세 화면까지 갈 수 있고, 사진 위 번호 상자도 정상으로 그려진다.

**AC-03 · 기존 입력이 그대로 동작한다**
- GIVEN: 샘플 버튼이 추가된 첫 화면이다.
- WHEN: 사용자가 직접 사진을 촬영하거나 업로드한다.
- THEN: 기존과 똑같이 분석된다.

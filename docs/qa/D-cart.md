# D. 장바구니

> **차터** — 장바구니 API를 탐색한다 / 담기·빼기·중복·빈 상태로 /
> **수량이나 합계가 틀어지는 조건**을 찾기 위해

| | |
|---|---|
| 담당 | |
| 타임박스 | 30분 |
| 실시일 | |
| 대상 | 배포 서버 `/api/cart`, `/api/cart/items` (커밋 `ff48749`) |

## 배경 — 알아둘 두 가지

**1. 로그인이 없다.** 카트는 브라우저가 만든 UUID를 `X-Cart-Id` 헤더로 보내서 구분한다.
헤더가 없으면 요청 자체가 안 된다. 처음 보는 ID를 보내면 빈 카트를 돌려준다
("카트 만들기" 요청이 따로 없는 이유다).

**2. 카트는 서버 메모리에만 있다.** DB에 저장되지 않는다.
→ **서버가 재시작되면 모든 카트가 사라진다.** HF Spaces는 유휴 상태에서 잠들었다 깨어나므로
실사용에서도 일어날 수 있다. 이게 의도된 동작인지 확인하는 게 D-09다.

수량은 `quantity_delta` 로 더하거나 뺀다(절대값을 넣는 게 아니다). 수량이 0 이하가 되면 그 줄은 사라진다.

## 실행 명령어

카트 ID를 하나 정해두고 시작한다:

```bash
CART=$(python3 -c "import uuid; print(uuid.uuid4())") && echo "CART=$CART"
```

빈 카트 조회:

```bash
curl -s https://hju5022-k-menu.hf.space/api/cart -H "X-Cart-Id: $CART" | python3 -m json.tool
```

담기 (수량 +1):

```bash
curl -s -X POST https://hju5022-k-menu.hf.space/api/cart/items -H "X-Cart-Id: $CART" -H "Content-Type: application/json" -d '{"food_id":1,"name_kr":"비빔밥","name_en":"Bibimbap","price_krw":9000,"quantity_delta":1,"menu_text":"비빔밥"}' | python3 -m json.tool
```

빼기 (수량 -1) — 위 명령에서 `"quantity_delta":1` 을 `-1` 로 바꾼다.

비우기:

```bash
curl -s -X DELETE https://hju5022-k-menu.hf.space/api/cart -H "X-Cart-Id: $CART" | python3 -m json.tool
```

## 테스트 케이스

| ID | 확인할 것 | 기대 결과 | 실측 결과 | 판정 | 심각도 |
|---|---|---|---|---|---|
| D-01 | 처음 보는 카트 ID로 조회 | 에러가 아니라 **빈 카트** (`total_krw` 0) | | | |
| D-02 | 음식 1개 담기 | 항목 1개, 수량 1, 합계 = 가격 | | | |
| D-03 | 같은 음식 또 담기 | **항목이 2개로 늘지 않고 수량이 2로** 올라감 | | | |
| D-04 | 수량 -1 | 수량이 1로 줄고 합계도 함께 줄어듦 | | | |
| D-05 | 수량이 0이 될 때까지 빼기 | 그 줄이 목록에서 사라짐 | | | |
| D-06 | 카트에 없는 음식을 -1 | 아무 일도 일어나지 않음 (에러도, 음수 수량도 없음) | | | |
| D-07 | 가격이 없는 항목 (`price_krw` 를 `null` 로) | 줄 합계가 비어 있고, **전체 합계가 깨지지 않음** | | | |
| D-08 | 다른 카트 ID로 조회 | 앞 카트 내용이 **보이지 않음** (격리) | | | |
| D-09 | 담아둔 뒤 서버가 잠들었다 깨어난 후 조회 | 내용 확인 → 사라진다면 의도된 동작인지 팀 확인 | | | |
| D-10 | `X-Cart-Id` 헤더 없이 요청 | 422 (500 아님) | | | |
| D-11 | 비우기 | 항목 0개, 합계 0 | | | |
| D-12 | 여러 종류 담기 | 합계 = 각 줄 합계의 총합 | | | |

### 특히 노려볼 것

- **합계 계산** — 가격이 있는 항목과 없는 항목을 섞었을 때 총합이 맞는가
- **같은 음식, 다른 메뉴판 줄** — 메뉴판에 같은 음식이 두 줄로 적혀 있을 때 각각 따로 담기는가, 합쳐지는가
- **큰 수량** — `quantity_delta` 에 999를 넣으면?

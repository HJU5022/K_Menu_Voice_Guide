# docs/

프로젝트 문서를 모아두는 곳입니다.

| 파일 | 내용 |
|---|---|
| `기획서.md` | 문제 정의·해결 방식·범위·성공 기준·일정 |
| `pipeline_diagram.png` | 전체 파이프라인 흐름도 (이미지, 별도로 추가 필요) |
| `specs/` | 기능별 Spec 문서 |

## Spec 작성 규칙

기능을 구현하기 **전에** `specs/{기능명}.md`를 먼저 씁니다. 형식은 `specs/_example.md`를 그대로 따르고, 다섯 섹션(Why · Goal · What · How · AC)이 모두 채워져야 합니다.

자세한 내용은 루트의 [AGENTS.md](../AGENTS.md)를 참고하세요.

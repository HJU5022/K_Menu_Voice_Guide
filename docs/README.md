## Spec 작성 규칙

기능을 구현하기 **전에** `specs/{기능명}.md`를 먼저 씁니다. 형식은 `specs/_example.md`를 따르고, 다섯 섹션(Why · Goal · What · How · AC)을 모두 채웁니다.

자세한 내용은 루트의 [AGENTS.md](../AGENTS.md)를 참고하세요.

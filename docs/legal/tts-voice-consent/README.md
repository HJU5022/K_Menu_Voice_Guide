# TTS Voice Consent

TTS 파인튜닝 및 평가에 사용한 팀원 음성 녹음 동의서를 보관하는 폴더입니다.

## 파일 구성

- `voice-consent-template.md`: 실제 서명용 원본 템플릿
- `voice-consent-public-redacted.md`: GitHub 공개용 가림본 예시

## 저장 원칙

- 공개 저장소에는 개인정보를 가린 버전만 올립니다.
- 이름, 연락처, 이메일, 서명 이미지, 상세 주소, 생년월일, 식별번호는 공개본에서 제거합니다.
- 원본 서명본은 팀 내부 비공개 저장소 또는 Drive에 따로 보관합니다.

## 권장 파일명

- 원본: `voice-consent-tts-{member-name}-2026-08-23-original.pdf`
- 공개본: `voice-consent-tts-{member-name}-2026-08-23-redacted.pdf`

## 운영 메모

- 이 폴더의 Markdown은 템플릿과 공개본 예시입니다.
- 실제 제출은 이 내용을 바탕으로 PDF로 저장해 사용하는 것을 권장합니다.
- TTS 실험 문서의 동의 언급은 [`eval/TTS_MODULE.md`](../../../eval/TTS_MODULE.md)에서 참조합니다.

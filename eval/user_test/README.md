# 외부 사용자 테스트 (2026-08-29)

팀 밖 사용자 3명이 **배포된 실서비스**를 직접 써보고 채점한 결과다. 팀 내부 예비 채점
(`eval/mos_scores.csv`, 1명)과는 평가 도구도 표본도 다르므로 **합산하지 않는다.**

| 파일 | 내용 |

| [`결과보고서.md`](./결과보고서.md) | 집계·해석·한계 |

| [`form_questions.md`](./form_questions.md) | 설문 24문항 (영어·한국어 병기) |

## 대표 지표

| 지표 | 값 |
|---|:--:|
| 전체 MOS | **4.33 / 5.0** (SD 0.58) |
| 한국어 이름 발음 | 4.44 (SD 0.73) |
| 명료도 | 4.33 (SD 0.71) |
| 자연스러움 | 4.22 (SD 0.83) |

## 인용할 때

- **반드시 `n=3`과 SD를 함께 적는다.** 응답 3건은 통계적 유의성이 없고 방향성 확인 용도다.
- 평균보다 **여러 명이 겹쳐 말한 것**이 신뢰할 만한 신호다. 3명 전원이 음성의 흐름(choppy /
  slow / fluency)을 지적했는데, 이는 척도 점수(자연스러움 4.22)로는 잡히지 않았다.

## 개인정보

`responses.csv`에는 이메일·이름이 없다. 참가자는 번호(P1~P3)로만 구분된다.
